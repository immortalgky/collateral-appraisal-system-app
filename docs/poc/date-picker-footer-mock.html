Date + Time picker — จัดวาง footer ใหม่

ปฏิทินไม่ได้กำหนดความกว้าง (absolute right-0 ไม่มี w-*) มันจึงกว้างเท่า ลูกที่กว้างที่สุด — กริดวันกว้าง 196px + padding = 212px แต่ footer แถวเดียวที่มี Today + Time + 00:00 + Done ต้องการ ~250px footer จึงเป็นตัวดันปฏิทินให้กว้างเกิน เส้นประใต้ปฏิทินแต่ละอันคือ 212px ไว้เทียบว่าอันไหนล้น

กดปุ่มในปฏิทินได้จริงทุกอัน — เปลี่ยนเดือน, กด Today, กางชั่วโมง/นาที

สิ่งที่ยังเหมือนเดิมทุกแบบ

  • Today แค่เลื่อนปฏิทินมาเดือนนี้ ไม่ได้เลือกวันให้ — ฟิลด์ที่ห้ามเลือกวันนี้จึงยังกดได้ปกติ
  • ชั่วโมง/นาที กางขึ้นบน เพราะอยู่ล่างสุดของ popover
  • Done แค่ปิด popover แล้วยิง onBlur ให้ validation ของฟอร์มทำงาน — ไม่ได้ commit ค่าอะไรเพิ่ม
