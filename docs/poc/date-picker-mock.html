Date Picker POC

ปฏิทิน + ช่องกรอกวันที่แบบใหม่ — พิมพ์แก้ทีละส่วน, ปฏิทินเปิดเฉพาะตอนกดไอคอน, ปุ่ม Today อยู่หน้าแรก, ไฮไลต์วันหยุด

นี่คือ mock เพื่อดู UX เท่านั้น — ไม่ได้ต่อ API และยังไม่ได้แก้โค้ดจริงสักไฟล์
วันหยุดในนี้เป็น ข้อมูลตัวอย่างที่ hardcode ไว้ (ตาราง workflow.Holidays ของจริงยังว่างเปล่า และรอบนี้ตกลงกันว่ายังไม่ทำฝั่งข้อมูล) — ทำแค่ให้ component รับ prop มาแสดงผลได้
วันนี้ในเครื่อง =

1. Purchase Date — วันที่อย่างเดียว (ห้ามเลือกอนาคต)

ช่องเดียวกับในภาพที่ส่งมา (disableFutureDates) วันหยุดขึ้นสีแดงแต่ยังเลือกได้

2. Appointment Date & Time — มีเวลาด้วย (ห้ามเลือกอดีต)

กรอก dd/mm/yyyy hh:mm ได้ตรง ๆ ในช่อง เลื่อนไปส่วนชั่วโมง/นาทีด้วย → หรือ :

3. ตัวอย่าง disableHolidays — ห้ามเลือกวันหยุด

prop เสริมสำหรับช่องที่ห้ามลงวันหยุดจริง ๆ (เช่นวันนัดตรวจ) วันหยุด+เสาร์อาทิตย์กดไม่ได้ และถ้าพิมพ์ตรงวันหยุดจะขึ้น error

4. สถานะอื่น ๆ

ค่าที่ส่งเข้าฟอร์ม (react-hook-form)

commit เฉพาะตอนกรอกครบและวันที่ถูกต้องเท่านั้น — รูปแบบ ISO เดิมไม่เปลี่ยน 


      


      

        
คีย์บอร์ดที่ลองได้

        

          
คลิก ในช่องเลือกเฉพาะส่วนที่คลิก (วัน / เดือน / ปี / ชม. / นาที) — ปฏิทินไม่เด้ง

          
0–9พิมพ์ทับเฉพาะส่วนนั้น แล้วกระโดดส่วนถัดไปเองเมื่อครบ

          
↑ ↓บวก/ลบค่าของส่วนที่เลือก (วนรอบ) — ส่วนที่ยังว่างเริ่มจากค่าวันนี้

          
← →ย้ายไปส่วนก่อนหน้า / ถัดไป

          
/ : Spaceยืนยันส่วนปัจจุบันแล้วไปส่วนถัดไป

          
Backspaceล้างส่วนที่เลือก กดซ้ำเมื่อว่างแล้วจะถอยไปลบส่วนก่อนหน้าต่อ (กดค้างลบย้อนได้ทั้งช่อง) — Delete ล้างเฉพาะส่วนที่เลือก ไม่ถอย

          
Escปิดปฏิทิน

          
วาง (paste)วาง 04/09/2026 หรือ 04/09/2026 14:30 ได้ทั้งก้อน

ปุ่ม Todayเดิมซ่อนในแผงเดือน/ปี → ย้ายมาอยู่ footer ของหน้าแรก (กดแล้วแค่เลื่อนปฏิทินมาเดือนนี้ ไม่เลือกวันให้)

          
เปิดปฏิทินเดิมคลิกที่ไหนในช่องก็เด้ง → เฉพาะไอคอน (โหมดช่วงวันที่ยังคลิกช่องได้เหมือนเดิม เพราะเป็น read-only)

          
การพิมพ์เดิมพิมพ์แก้เดือนต้องลบใหม่ทั้งหมด → แก้ทีละส่วน + ล็อกฟอร์แมต

          
พิมพ์ค้างครึ่ง ๆเดิมทิ้งข้อความขยะไว้ในช่อง → blur แล้วย้อนกลับค่าที่ commit ล่าสุด

          
วันหยุดเดิมไม่มีเลย → รับ prop holidays มาไฮไลต์ + tooltip ชื่อวันหยุด
