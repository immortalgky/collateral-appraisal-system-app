หน้าแก้กฎหมายและข้อบังคับ — เน้นรูปประกอบ

ชื่อหัวข้อ ข้อความ และรูปในหน้านี้เป็นตัวอย่าง (master "หัวข้อ" ในระบบตอนนี้ยังเป็น 01/02/03/99) — ลองลากรูปเพื่อเรียงลำดับ พิมพ์คำบรรยาย หรือกด × เอารูปออกได้

ตอนนี้เป็นแบบนี้

  • การ์ดรูปใหญ่ 4 ต่อแถว + ช่องเพิ่มขนาดเท่ารูป — 6 รูปก็เลื่อนจอแล้ว
  • ใต้รูปเป็นชื่อไฟล์ ขนาดไฟล์ "PNG · 1.86 MB" ซึ่งไม่มีใครใช้ ส่วนคำบรรยายต้องเปิดรูปใหญ่ถึงแก้ได้ และแก้คำบรรยายในแกลเลอรี (ใช้ร่วมทั้งใบ)
  • รูปที่ถูกลบจากแกลเลอรีแล้วยังค้างอยู่ในหัวข้อ — ขึ้นรูปแตก "Photo 2" (ใบ 69000170 หัวข้อ 01 รูปที่ 2 เป็นแบบนี้จริง)
  • เรียงลำดับไม่ได้ ทั้งที่มี DisplaySequence
  • ยืนยันลบบอก "ย้อนกลับไม่ได้" แต่จริง ๆ แค่เอาออกจากหัวข้อ รูปยังอยู่ในแกลเลอรี และยังไม่บันทึกจนกด Save
  • ข้อความอังกฤษทั้งหน้า: Edit Law & Regulation · Header · Images · Add photos · Save draft

ที่เปลี่ยน

  • หัวหน้าคือชื่อหัวข้อกฎหมาย (ดรอปดาวน์เดิม) แทนคำว่า "Edit Law & Regulation"
  • รูปเล็กลง มีเลขลำดับ ลากเพื่อเรียง · × = เอาออกจากหัวข้อ ไม่ต้องยืนยัน (ยังไม่บันทึกจนกด บันทึก)
  • คำบรรยายพิมพ์ใต้รูปได้เลย ใช้ช่อง Description ของรูปในหัวข้อนี้ (มีใน DB อยู่แล้วแต่ไม่เคยมีช่องให้กรอก)
  • รูปที่หายจากแกลเลอรี → กรอบแดง "รูปนี้ถูกลบจากแกลเลอรีแล้ว" + ปุ่มเอาออก
  • ปุ่ม อัปโหลด / เลือกจากแกลเลอรี อยู่ตรงนั้นเลย ไม่ต้องผ่านหน้าต่างเลือกแหล่งก่อน · ลากไฟล์มาวางได้เหมือนเดิม
  • ไม่แก้ BE — ใช้ API บันทึกเดิม

อยากให้ตัดสินใจ

  • A หรือ B — A: ข้อความกับรูปเห็นพร้อมกัน เหมาะกับจอกว้าง · B: รูปได้พื้นที่มากกว่า
  • คำบรรยายเป็นของหัวข้อนี้ หรือของรูปในแกลเลอรี? — ของหัวข้อ: รูปเดียวกันใช้ต่างหัวข้อบรรยายต่างกันได้ (เสนอแบบนี้) · ของแกลเลอรี: แก้ที่เดียวเห็นทุกที่ แบบที่เป็นอยู่
  • ชื่อหัวข้อจริงของ master "หัวข้อ" (ค้างอยู่ใน backlog)
