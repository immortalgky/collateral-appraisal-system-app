หัวฟอร์มทรัพย์สิน: รูปภาพ + ส่วนหัวรายละเอียด

ใช้ร่วมกัน 9 หน้า (ที่ดิน · อาคาร · ที่ดินและสิ่งปลูกสร้าง · ห้องชุด · เครื่องจักร · สิทธิการเช่า 4 แบบ) กดสลับแบบ ความกว้าง ประเภททรัพย์ และสถานะด้านบนเพื่อเทียบ — รูปในนี้เป็นภาพตัวอย่างวาดด้วย CSS

บอกว่ากำลังแก้ทรัพย์ชิ้นไหนไม่บอก (มีแค่ breadcrumb)ชื่อ + ประเภท + ข้อมูลหลัก + ภาพหน้าปกชื่อ + ประเภท บรรทัดเดียว
แถบแท็บ"รูปภาพ" เลื่อนจอ แต่ที่เหลือสลับเนื้อหา หน้าตาเหมือนกันแท็บจริงล้วน ขีดใต้แบบเดียวกับแท็บหน้าหลักแท็บจริงล้วน
ตอนเลื่อนลงแถบแท็บค้าง รูปเลื่อนหายยุบเป็นแถบเล็ก: หน้าปก + ชื่อ + แท็บแถบแท็บค้าง แถบรูปเลื่อนหาย
ขนาดงาน—component หัวใหม่ 1 ตัว + แก้ 9 หน้าเล็กกว่า: เปลี่ยนแถบรูป + แท็บ

ใช้ของเดิมทั้งหมด ไม่แก้ BE

  • อัปโหลด / เลือกจากแกลเลอรี / ตั้งหน้าปก / ลบ / ดูรูปใหญ่ — ยังเป็น PropertyPhotoSection ตัวเดิม เปลี่ยนแค่หน้าตา
  • บรรทัดข้อมูลหลักอ่านจากค่าในฟอร์มสด ๆ (โฉนด เนื้อที่ ที่ตั้ง) พิมพ์แล้วหัวเปลี่ยนตาม ไม่ต้องเรียก API เพิ่ม
  • ช่องที่ยังไม่กรอกขึ้นตัวเอียงสีจาง เช่น "ยังไม่ระบุที่ตั้ง" แทนการซ่อน
